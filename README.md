# Personal Website

My personal portfolio website built with React, TypeScript, and Tailwind CSS.

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- Vercel (deployment)

## Run Locally

```bash
# Clone the repository
git clone https://github.com/rahuljoban/personal-website.git

# Navigate to the project
cd personal-website

# Install dependencies
npm install

# Start the development server
npm run dev
